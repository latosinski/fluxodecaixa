# Cash Pró — Fluxo de Caixa

Landing page institucional e comercial do sistema **Cash Pró — Fluxo de Caixa**, desenvolvida em Next.js (App Router) com TypeScript e CSS customizado.

O projeto apresenta os recursos do sistema, tela de demonstração, preço, formulário de contato e link direto para a versão demo (`/sistema/`), servida estaticamente a partir da pasta `public/`.

---

## Tecnologias

- **Next.js** (última versão estável, App Router + Turbopack)
- **TypeScript**
- **React 19**
- **CSS puro** (arquivo único `globals.css`, sem frameworks como Tailwind)
- **next/font** (Google Fonts: Inter e Playfair Display)
- **@phosphor-icons/react** (ícones)
- **AOS** (animações on-scroll)
- **Route Handlers** (API interna para o formulário de contato)

---
